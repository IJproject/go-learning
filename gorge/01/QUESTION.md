# ログ集計ミニダッシュボード

## やること

与えられたアクセスログ（文字列スライス）を集計して、次の情報を出力するプログラムを書け。

1. ステータスコードごとの件数（例：200 が何回、404 が何回）
2. パスごとの件数（例：/home が何回）
3. 一番アクセス数が多いパス とその回数

※ 同数 1 位が複数なら、どれか 1 つでいい

```go:サンプルデータ
logs := []string{
  "GET /home 200",
  "GET /products 200",
  "POST /products 201",
  "GET /home 200",
  "GET /about 404",
  "GET /home 500",
  "GET /products 200",
  "GET /products 200",
  "GET /about 404",
}
```

## 出力要件

フォーマットは自由。ただし上の 3 つが人間に読める形で全部出てれば OK。

## 目的

- 文字列分割と整形
- map による頻度カウント
- for と条件分岐の基礎運用
- 集計結果から最大値を見つけるロ
