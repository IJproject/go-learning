# 成績処理クラス

## やること

学生の成績を扱うプログラムを書け。

1. Student 構造体を作る
   1. Name string
   2. Scores []int
2. Student に以下のメソッドを実装する
   1. Average() float64：平均点
   2. Max() int：最高点
   3. Min() int：最低点
3. 複数学生をスライスで持ち、以下を出力する
   1. 全員の平均点一覧
   2. クラス全体の平均点

```go:サンプルデータ
students := []Student{
  {"Aki", []int{80, 70, 90}},
  {"Ben", []int{60, 75, 65, 70}},
  {"Cara", []int{100, 95}},
  {"Dan", []int{50, 40, 55}},
}
```

## 出力要件

- 各学生の Average/Max/Min
- クラス全体平均

## 目的

- struct の設計と初期化
- レシーバ付きメソッドの基本
- スライス走査と集計
- float64 計算と型変換の扱い
